НОМЕРНОЙ КЛУБ — версия 3.0

Что изменено:
- При открытии сразу показывается генератор с номером.
- Касание области с номером мгновенно генерирует следующий номер, без анимационной задержки.
- Кнопки меню снизу убраны; три полоски в левом верхнем углу открывают меню.
- Локальное сохранение и офлайн-кэш PWA.
- Панель разработчика: Настройки → Войти как разработчик → 171214.

Запуск/установка:
1. Распакуйте ZIP.
2. Разместите все файлы в корне сайта с HTTPS (например, GitHub Pages).
3. Откройте HTTPS-адрес в Chrome на Android и выберите «Установить приложение» / «Добавить на главный экран».
4. После первого открытия дождитесь загрузки иконки/страниц; затем приложение сможет открываться офлайн.

Важно: офлайн-режим работает после первой успешной загрузки по HTTPS. Глобальная выдача валюты/оповещения для всех игроков требуют сервера; в этой версии инструменты локальные. Валюта игровая.
